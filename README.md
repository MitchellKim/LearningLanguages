# LearningLanguages

A small repository for collecting resources, exercises, and notes to help learn modern languages.

## About

This repo contains study materials and simple practice projects to help you learn new programming languages and language features quickly.

## What's inside

- Language-specific examples and exercises
- Notes and tips
- Small practice projects and snippets

## Getting started

1. Browse the folders for the language you want to study.
2. Read the notes in each folder and run the example projects.
3. Open an issue or submit a pull request if you want to contribute or suggest improvements.
